# Prototypes

- `shell-demo/`: interactive web mockup; simulated controls only.
- `compositor/`: Smithay experiment; development status in its README.
- `shell/`: GTK4 host-window launcher; not yet integrated into compositor.
- `live-build/`: Debian live ISO recipe starter.

Builds and prototypes are not equivalent to a complete, installable UNNAMED OS. See docs/KNOWN_LIMITATIONS.md.
